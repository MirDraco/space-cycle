PRIVACY POLICY

개인정보 처리방침

Space Cycle 팀(이하 ‘팀’)은 수업용 시범 서비스인 Space Cycle(https://spacecycle.space)을 운영하며, 이용자의 개인정보와 위치정보를 아래와 같이 처리합니다.

시행일 2026년 11월 13일

1. 처리하는 개인정보 항목

구분항목수집 시점
로그인Google 계정 고유 ID(UID), 이름, 이메일, 프로필 사진 주소Google 로그인 시
방문 기록계정 UID, 공간 ID, 최초 완료 시각체류 완료 시
진행 기록계정 UID, 공간 ID, 시작·준비·만료 시각, 시작 요청 식별값‘위치 확인하고 시작’ 시
위치정보위도, 경도, 위치 정확도시작·마지막 위치 확인 버튼을 누를 때
자동 생성접속 IP 주소, 브라우저 정보(서비스 전달·보안 과정에서 처리)사이트 접속 시

이름·이메일·프로필 사진은 Google 로그인(Firebase Authentication)이 보관하며, 팀의 서버 DB에는 계정 UID만 저장합니다.

2. 처리 목적

  • 로그인과 계정 식별, 다른 계정의 기록 접근 방지
  • 공간 체류 시작·종료 위치가 허용 반경 안인지 판정
  • 계정별 ‘내가 찾은 스페이스’ 기록과 개수 표시, 중복 집계 방지
  • 새로고침·화면 전환 후 진행 상황 복구, 부정 요청과 과도한 요청 차단

3. 위치정보의 수집·이용

  • 언제: 이용자가 ‘위치 확인하고 시작’ 또는 ‘마지막 위치 확인’ 버튼을 직접 누를 때만 위치를 요청합니다. 대기 중이나 다른 화면에서는 위치를 요청하지 않습니다.
  • 어떻게: 브라우저가 측정한 위도·경도·정확도를 서버로 보내, 공간 중심점까지의 거리를 계산합니다.
  • 보관: 원본 좌표와 정확도는 판정 직후 버리며 DB·로그에 저장하지 않습니다. 판정 결과(시작·완료 여부와 시각)만 위 1번의 진행·방문 기록으로 남습니다.
  • 제공: 위치정보를 제3자에게 제공하지 않습니다.
  • 동의: 처음 위치를 확인하기 전에 화면에서 동의를 받습니다. 브라우저 설정에서 이 사이트의 위치 권한을 끄면 언제든 동의를 철회할 수 있으며, 이 경우 체류 확인 기능만 이용할 수 없습니다.

4. 보유 기간과 파기

  • 진행 기록·시작 요청 식별값: 시작 후 최대 2시간이 지나면 자동 삭제
  • 방문 기록: 삭제 요청 시 또는 프로젝트 운영 종료 시 지체 없이 삭제
  • 위치정보 원본: 저장하지 않음(판정 즉시 파기)
  • Google 로그인 정보: 이용자가 로그아웃해도 Firebase 계정은 남으며, 삭제 요청 시 함께 삭제

전자 파일은 복구할 수 없는 방법으로 삭제합니다. 운영 중 장애 대비용 DB 백업도 같은 기준으로 관리하고, 운영 종료 시 함께 삭제합니다.

5. 처리 위탁과 국외 이전

받는 자업무·항목국가·시점·기간
Google LLC (Firebase Authentication)Google 로그인 처리: UID, 이름, 이메일, 프로필 사진 주소미국 등 · 로그인 시 네트워크로 전송 · 계정 삭제 시까지
Cloudflare, Inc.사이트 전달·보안(HTTPS, 터널): 접속 IP, 요청 정보미국 등 · 접속 시 네트워크로 전송 · Cloudflare 정책에 따름

국외 이전을 원하지 않으면 로그인하지 않을 수 있으나, 이 경우 계정별 기록 저장 기능을 이용할 수 없습니다. 팀은 개인정보를 판매하거나 광고 목적으로 제공하지 않습니다.

6. 이용자의 권리와 행사 방법

이용자는 언제든 자신의 개인정보 열람, 정정, 삭제, 처리 정지를 요청할 수 있습니다. 아래 연락처로 로그인한 Google 계정 이메일과 함께 요청하면 본인 확인 후 지체 없이(최대 10일 이내) 처리하고 결과를 알려드립니다.

7. 브라우저 저장 정보

광고·추적 쿠키를 사용하지 않습니다. 화면 테마와 위치 이용 동의 여부는 이 기기의 브라우저 저장소에만 보관하며, 로그인 유지 정보는 Firebase가 브라우저 저장소에 보관합니다. 브라우저의 사이트 데이터 삭제로 지울 수 있습니다.

8. 안전성 확보 조치

  • 모든 통신 HTTPS 암호화, 서버에서 로그인 토큰 서명 검증
  • DB에는 이메일·이름·좌표를 저장하지 않고 계정 UID만 저장
  • DB 파일 접근 권한 제한(운영자 계정만), 서버 포트 외부 비공개
  • 계정별 요청 횟수 제한으로 무단 조회·과도한 요청 차단
