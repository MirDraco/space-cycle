시작·종료 위치와 시간 확인, 중간 연속 체류는 검증하지 않아요.

로그인 후 시작·종료 버튼을 누를 때만 위치 권한을 요청해요. 확인한 위도·경도·정확도를 서버로 보내 반경을 판정해요. 원본 좌표는 저장하지 않으며, 진행 복원을 위해 계정 ID·공간 ID·시작 시각·만료 시각을 저장해요. 완료한 계정 ID·공간 ID·최초 완료 시각도 저장해요.

체류 조건과 위치 안내

시작 위치가 허용 반경과 정확도 조건을 만족하면 서버에서 대기 시간을 세요. 대기 중에는 위치나 서버 확인을 반복하지 않아요. 필요한 시간은 위 조건과 남은 시간에 표시하며 서버의 공간별 설정을 따라요.

새로고침, 화면 전환, 인터넷 끊김으로 진행을 지우지 않아요. 같은 계정으로 돌아오면 위치 권한 요청 없이 서버의 진행을 불러와요. 진행은 시작 후 최대 2시간 유지되며, 유효기간이 지나면 다시 시작해야 해요. 다른 계정에서는 원래 계정의 진행을 볼 수 없어요.

00:00은 완료가 아니에요. ‘마지막 위치 확인’ 버튼을 직접 눌러 새 위치를 보내고 서버가 시간·위치·기록 저장을 승인해야 완료돼요. 종료 위치의 정확도 부족이나 반경 이탈, GPS·통신 오류가 있어도 기다린 진행은 유지하며 다시 확인할 수 있어요.

시작·종료 위치 획득은 각각 시도당 최대 15초, 전체 최대 30초예요. 응답 시간 초과나 오래된 측정값은 짧게 쉬고 다시 확인하지만 전체 기한을 늘리지는 않아요. 시작 위치를 찾는 시간은 대기 시간에 포함하지 않아요.

‘진행 취소’를 누르면 서버의 취소를 확인한 후 화면을 비워요. 취소 응답을 받지 못하면 진행을 다시 불러와 확인해요. 이미 저장된 ‘내가 찾은 스페이스’ 기록은 취소해도 삭제하지 않아요.

테스트 반경은 300m예요. 정확도는 50m 이하이고, 중심점까지 거리와 정확도의 합이 300m 이하여야 해요. 실내 GPS가 불안정하면 창가 등 신호가 잘 잡히는 안전한 곳에서 다시 시도해주세요. 반경은 자동으로 넓히지 않아요.

측정값이 오래됐거나 이전 측정 시각이 반복되면 그 위치는 보내지 않고 새 위치를 다시 받아요. 화면의 위치 응답 대기 시간·측정값 나이·gps_ 코드는 이 기기에서만 표시하며 원본 좌표나 로그인 토큰을 진단 기록으로 저장하지 않아요.

Android에서 지연이 계속되면 설정 → 앱 → Chrome → 권한 → 위치에서 정확한 위치 사용 여부와, 설정 → 위치 → 위치 서비스 → 위치 정확도 개선을 확인해주세요. 기기마다 메뉴 이름은 다를 수 있어요.

서버가 완료를 확인하고 저장하면 로그인한 계정의 ‘내가 찾은 스페이스’에 추가해요. 같은 공간은 여러 번 완료해도 1곳으로 세요. 뱃지·스티커 보상은 아직 없어요. QR 링크나 브라우저 GPS만으로 방문 조작을 완전히 차단하지는 못해요.
