로그인 후 버튼을 누르면 위치 권한을 요청해요. 확인한 위도·경도·정확도를 서버로 보내 반경을 판정해요. 원본 좌표는 저장하지 않으며 완료한 계정 ID·공간 ID·최초 완료 시각만 저장해요.

체류 조건과 위치 안내

화면을 켜두고 이 페이지에 머물러주세요. 짧은 위치 응답 지연은 자동으로 다시 확인하며, 대기 중 남은 시간은 마지막 서버 확인값으로 표시해요. 반경 이탈, 위치 정확도 부족, 서버가 정한 위치 재확인 기한 만료, 통신 끊김, 다른 화면 이동, 새로고침 시 시간은 처음부터 다시 시작해요.

처음 위치를 찾는 동안은 최대 30초 기다리며 아직 체류로 세지 않아요. 위치 응답 시간 초과가 한 번 발생했다고 즉시 초기화하지 않아요.

위치 획득 최대 시간과 확인 기한은 서버가 내려줘요. 현재 기본값은 위치 획득15초·확인 기한25초이며 통신 여유5초를 남겨요. 이전6초 제한은 제거했지만, 새 위치 없이 시간을 무제한 인정하지는 않아요. 실제 적용값과 서버 확인 횟수는 화면 진단에 표시돼요.

남은 시간은 마지막 서버 확인값을 기준으로 매초 이어서 보여줘요. 00:00이어도 서버에서 마지막 위치와 체류를 승인해야 완료되고 기록이 저장돼요.

테스트 반경은 300m예요. 정확도는 50m 이하이고, 중심점까지 거리와 정확도의 합이 300m 이하여야 해요. 실내 GPS가 불안정하면 창가 등 신호가 잘 잡히는 안전한 곳에서 다시 시도해주세요. 반경은 자동으로 넓히지 않아요.

측정값이 오래됐거나 이전 측정 시각이 반복되면 그 위치는 보내지 않고 새 위치를 다시 받아요. 화면의 위치 응답 대기 시간·측정값 나이·gps_ 코드는 이 기기에서만 표시하며 원본 좌표나 로그인 토큰을 진단 기록으로 저장하지 않아요.

Android에서 지연이 계속되면 설정 → 앱 → Chrome → 권한 → 위치에서 정확한 위치 사용 여부와, 설정 → 위치 → 위치 서비스 → 위치 정확도 개선을 확인해주세요. 기기마다 메뉴 이름은 다를 수 있어요.

1분 체류를 완료하면 로그인한 계정의 ‘내가 찾은 스페이스’에 저장해요. 같은 공간은 여러 번 완료해도 1곳으로 세요. 뱃지·스티커 보상은 아직 없어요. QR 링크나 브라우저 GPS만으로 방문 조작을 완전히 차단하지는 못해요.
